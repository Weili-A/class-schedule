# 📅 我的课程表（PWA）

一个为 iPhone 设计的中文课程表网页 App。**单双周、只上几周的课、调休停课**都能准确显示：每一周上什么课、几点上、在哪上。

- ✅ 单双周自动判断（按学期"第几周"计算，可一键校准）
- ✅ 限周课程：`前4周`、`第1-4周`、`第5-8周`、`第2,3,5-7周` 等任意周次
- ✅ 调休 / 停课：法定节假日一键停课；调休周末"按周一上课"
- ✅ 今天视图：正在上/下一节课 + 倒计时 + 地点
- ✅ 周课表：前后翻周，单双周自动过滤
- ✅ 导出到苹果日历（.ics），带课前 15 分钟提醒 → 补上 PWA 无法后台推送的缺口
- ✅ 数据只存本机（localStorage），无账号、无服务器、无广告、无追踪；支持 JSON 备份/导入
- ✅ 离线可用（Service Worker），深色模式自适应

> 纯前端，无任何依赖：核心逻辑 `schedule-core.js` 有 70 项单元测试（`node tests/schedule-core.test.js`）。

## 一、部署（免费，约 3 分钟）

PWA 必须通过 **HTTPS** 访问才能安装。推荐 GitHub Pages：

1. 注册/登录 [github.com](https://github.com)，点右上角 **+** → **New repository**。
2. Repository name 随意填（如 `class-schedule`），选 **Public**，不要勾选 README，点 **Create repository**。
3. 进入仓库页面 → 点 **uploading an existing file** 链接（或 **Add file → Upload files**）。
4. 把本项目里**除了 `tests`、`tools` 文件夹以外**的所有文件拖进去：
   ```
   index.html  styles.css  app.js  schedule-core.js  sw.js  manifest.webmanifest  icons/
   ```
   （README.md 可传可不传）→ 点 **Commit changes**。
5. 仓库页点 **Settings** → 左侧 **Pages** → **Branch** 选 `main`、目录选 `/ (root)` → **Save**。
6. 等约 1 分钟，页面上会显示你的网址：`https://你的用户名.github.io/class-schedule/`。

> 没有 GitHub 的话，Netlify Drop（拖文件夹即上线）、Vercel、Cloudflare Pages 同理。也可放在任何 HTTPS 静态托管。

## 二、装到 iPhone 上（变成"App"）

1. 用 **Safari** 打开你的网址（必须 Safari）。
2. 点底部 **分享按钮**（方框+上箭头）→ 下滑选 **添加到主屏幕** → 点 **添加**。
3. 回到主屏幕，点 **课程表** 图标打开 —— 全屏运行、离线可用。

> 以后更新了网页版，回到 Safari 打开一次网址即可自动更新 App 内容（缓存策略为网络优先）。

## 三、第一次使用

1. 首次打开会询问：**今天是第几周**（学期中途开始用也没关系，开学日期会自动推算）、**学期总周数**（默认 20）、**第1周是否为单周**（按教务处校历核验）。下方有实时预览："推算第1周从 8月31日（周一）开始；今天 = 第3周 · 单周"，确认无误再进入。
2. 可以**载入示例课程表**看看效果（覆盖每周/单双周/前4周/自定义周次），之后在"课程"里删掉改成自己的课；也可以**开始使用**（空白）。
3. 单双周规则：第 1 周 = 单周，第 2 周 = 双周，依此类推。

**周次规则怎么写**（录入课程时填）：

| 情况 | 填写 |
|---|---|
| 每周都上 | `每周` |
| 只上单周 | `单周` |
| 只上双周 | `双周` |
| 只上前 4 个周 | `前4周` |
| 第 5-8 周 | `第5-8周` |
| 第 3-15 周且只上双周 | `3-15双周` |
| 零散周次 | `第2,3,5-7周` |

填完立刻有预览："✓ 第1-4周，本学期共 4 次（第1、2、3、4周）"，所见即所得。

## 四、关键操作

- **单双周不对？** 设置 → 点"🎯 校准"：回答"今天是第几周"和"这周是单周还是双周"两个问题，App 会同时修正学期开始日期与单双周基准。
- **国庆/中秋停课**：设置 → 调休/停课 → 添加"停课"，选日期区间。以国庆为例：10月1-7日 添加一条停课；若 9月28日(周日)补周一的课、10月11日(周六)补周五的课，各添加一条"补课"。
- **调休补课进阶**：
  - 学校通知"补**第4周**周一的课"→ 补课条目里填"补第几周的课：4"（按该周单双取课，不会补错周）；
  - 补课日你本来还有别的课（如周末选修照常上）→ 勾选"同时保留当天原有的课"。
- **上课提醒**：设置 → 选择提醒分钟数（5/10/15/30/60）→ 导出到苹果日历 → 在"文件"App 点开 `我的课程表.ics` → 自动进入日历导入 → 点"全部添加"。**改课后请先在"日历"App 删除旧的课程事件，再重新导出导入**，避免重复提醒。
- **备份/换机**：设置 → 导出备份（优先走系统分享，可存备忘录/微信收藏）；新设备"导入备份"即可。

## 五、本地预览 / 开发

```bash
node tools/serve.js 8080     # 打开 http://localhost:8080（localhost 可注册 SW）
node tests/schedule-core.test.js   # 跑单元测试（98 项，含对抗式边界用例）
node tools/check-ids.js      # 静态检查 DOM id 引用一致性
node tools/gen-icons.js      # 重新生成图标
```

`tools/demo-test.html` 是自动化冒烟测试页（预置示例课程表后加载应用），可用无头浏览器 `--dump-dom` 验证渲染结果，部署时无需上传。

## 六、已知限制（诚实说明）

1. **无法主动推送通知**：本 App 是纯静态网页、没有推送服务器，iOS 不允许它在 App 关闭时发送通知。用"导出到苹果日历"获得系统级提醒。
2. **数据只存这一台设备的浏览器里**，不跨设备同步。请**务必"添加到主屏幕"**：iOS 会定期清理长期未访问的网页数据，安装成 App 后数据长期保存更可靠；并定期导出备份（换机用"导入备份"）。
3. **学期切换**：新学期记得改"学期开始日期/总周数"，课程列表可以继续沿用或清空重建。
4. 若学校以特殊"教学周"计周（与自然周错位），用"校准"同时设置周数与单双周即可对齐。
5. 若用 Safari 直接打开网址发现空白/旧数据：Safari 与主屏幕 App 的数据可能分开存放，从主屏幕图标打开即可找回，数据没有丢。
6. 导出日历后修改过课表，需先在日历删除旧事件再重新导出（旧日程不会自动更新）。

## 七、隐私

所有数据仅保存在你手机浏览器的本地存储中；本应用不包含任何网络请求、统计、广告或跟踪代码。
